Metodología

  1. Recopilamos automáticamente datos públicos de organismos internacionales y plataformas de datos abiertos.
  2. Cada evento se geolocaliza (coordenadas del incidente o centroide del país) y se clasifica por tipo y severidad.
  3. La severidad (info · warning · alert · critical) se calcula con umbrales por categoría (p. ej. volumen de desplazados o víctimas).
  4. Los eventos expiran automáticamente cuando la fuente deja de reportarlos, manteniendo el mapa actualizado.
  5. Todo es reproducible: código abierto, fuentes y criterios documentados.

Fuentes de datos

UNHCR Refugee Data Finder — stock de refugiados, solicitantes de asilo y desplazados internos por país. API pública anual. api.unhcr.org
IDMC — desplazamiento interno por conflicto y violencia, vía API de UNHCR. Datos anuales. internal-displacement.org
IOM DTM — stock de desplazados internos por operación y país (CSV global semanal). dtm.iom.int
Missing Migrants Project (IOM) — incidentes con muertos y desaparecidos en rutas migratorias, con coordenadas (CSV). missingmigrants.iom.int
ReliefWeb — noticias y alertas humanitarias (RSS). reliefweb.int
Distribución: HDX (Humanitarian Data Exchange) · data.humdata.org

Aviso legal

MigrationFlow OSINT es una recopilación independiente de datos públicos con fines informativos y de análisis. No está afiliado, respaldado ni patrocinado por UNHCR, IDMC, IOM ni HDX. Las cifras son estimaciones oficiales de las fuentes citadas y pueden estar sujetas a revisión. Los eventos que se muestran no constituyen una clasificación oficial de crisis ni sustituyen la información de las agencias humanitarias.

El mundo en movimiento, en un mapa

Seguimiento abierto de flujos migratorios y desplazamiento forzado a partir de datos públicos de UNHCR, IDMC, IOM y ReliefWeb. Cada punto es un evento real, actualizado de forma automática.

Para quién

  • Investigadores, periodistas y organizaciones humanitarias
  • Comunidades y personas en movimiento
  • Ciudadanía interesada en el fenómeno migratorio

Cómo se construye

Recopilación automática de fuentes oficiales, geolocalización, clasificación por severidad, expiración automática y documentación reproducible.
